## 一、赛题解读与得分点拆解

### 1.1 任务（赛题原文）

> 设计并制作拼图装置，能够控制机械臂或其他机构移动碎片，最终将所有碎片拼接成目标矩形。拼图区域为纵向 A4 纸张，碎片随机摆放在纸张的上半区域，装置将碎片移动到纸张的下半区域并完成拼图。

一句话概括：**"看得见 → 算得出 → 抓得稳 → 放得准"**，四项能力缺一不可，且全程自动、无人工干预。

### 1.2 硬性要求逐条拆解

#### 要求 1：选手自备 A4 纸与 4 片碎片（50 分）

| 序号 | 赛题原文约束 | 隐含工程含义 |
| --- | --- | --- |
| 1 | 自备 A4 纸，上下区域有**明显分界线**，实线宽度 **≤ 5 mm** | 分界线必须能被视觉稳定检出；宽度限制决定了不能用粗色带，只能靠**颜色对比**而非面积取胜 |
| 2 | 4 片碎片**纯色**、颜色一致、材质不限、厚度 **≤ 2 mm**、**无任何元器件** | 碎片上不能贴传感器/磁铁外露器件；但"材质不限"允许内部含铁——这是选型电磁抓取的关键依据 |
| 3 | 碎片移动方式不限 | 机构形态自由，为直角坐标 / 机械臂 / 推板等方案留出空间 |
| 4 | **2 分钟内一次性完成**两项操作 | 视觉 + 求解 + 抓放必须共享同一段时间预算，不能分两次启动 |
| 5 | (1) 所有碎片从上半区移动到下半区 —— **20 分** | 只要"分界线跨越"就算完成，属于保底分 |
| 6 | (2) 拼接成目标矩形：位置正确、不重叠、**相邻碎片对应顶点距离 ≤ 2 cm** —— **30 分** | 2 cm 是误差判据的总闸门，决定了视觉精度、机械重复定位精度、标定精度的下限 |

#### 要求 2：使用自备 A4，拼接测评现场碎片（50 分）

| 序号 | 赛题原文约束 | 隐含工程含义 |
| --- | --- | --- |
| 1 | 现场碎片数量 **≤ 4 片** | 求解规模很小，可用穷举/回溯而非启发式搜索 |
| 2 | 每片**边数 ≤ 5 条**，每条边长 **≥ 2 cm** | 多边形为凸/类凸简单形状，边长下限保证边匹配可行、视觉可分辨 |
| 3 | 每片**至少有 1 条边位于目标矩形外边上** | 目标矩形轮廓由碎片边拼成，可用来做矩形约束的强校验 |
| 4 | 镀锌薄铁片（约 **0.3 mm**）上黏贴纸片，总厚 **≤ 2 mm**，重量 **≤ 30 g** | 材料明确含铁 → **电磁铁吸合是首选抓取方式**；0.3 mm 铁片易变形，抓取力必须可控 |
| 5 | 目标矩形尺寸 **9 cm × 5 cm ~ 12 cm × 9 cm** | 给出了求解的尺寸搜索区间，是剪枝的关键约束 |
| 6 | (1) 现场碎片纸片为**纯白**：拼成目标矩形，精度同上，**时间 ≤ 2 分钟** —— **20 分** | 白碎片 + 浅色纸 = 低对比度风险，需要专门的对比度设计 |
| 7 | (2) 现场碎片为**白底扑克牌牌面**：还要求**相邻碎片花纹对应正确** —— **30 分** | 在几何解集内增加**纹理接缝一致性**评分，是区分度最高的一项 |

### 1.3 说明（赛题原文）中的"魔鬼细节"

| 说明 | 工程对策 |
| --- | --- |
| 测评时**先遮挡摄像头**，随机不重叠摆放碎片后，**再一键启动并同时移除遮挡**，计时开始 | ① 装置必须支持"启动瞬间画面是黑的"；② 移除遮挡后的画面跳变**不能**触发误判，必须有多帧稳定判据；③ 启动按钮与"移除遮挡"是同一时刻，视觉要能自适应曝光 |
| 装置**自动完成拼接，中途无人工干预** | 全流程状态机需自恢复：检测失败要自动重试，而不是停机等键 |
| 拼接完成后装置给出**声、光等指示**，计时结束 | 结束提示必须"看得见听得见"，建议蜂鸣器 + LED 双通道，且在最后一个动作完成后立即触发 |
| 装置应适应**正常室内照明**，测试时不得有特殊照明条件要求 | 不能依赖定向光源/暗室；阈值必须**可在线标定并掉电保存** |

## 二、方案论证与选择

> 本节是设计报告"方案论证（4 分）"的正文素材，建议按"提出 2~3 种方案 → 列表比较 → 给出结论"的写法成文。

### 2.1 碎片移动机构

| 方案 | 定位精度 | 结构复杂度 | 节拍 | 对现场铁片兼容性 | 结论 |
| --- | --- | --- | --- | --- | --- |
| **A. 直角坐标（XY）十字滑台 + 电动 Z 轴 + 电磁铁吸头** | 高（脉冲当量可达 0.01 mm 级） | 中 | 快（点对点直线运动） | **优**：电磁铁直接吸合镀锌铁片 | **选定** |
| B. 桌面级多轴机械臂 + 真空吸盘 | 中（受关节累计误差影响） | 高 | 中（圆弧插补、需要姿态规划） | 差：纸面/薄铁片真空吸附漏气，需平整面 | 否 |
| C. 推板/刮板机构（接触式推挤） | 低 | 低 | 快 | 中：无法精确旋转碎片 | 否 |
| D. 转盘 / 传送带 + 固定工位 | 低 | 中 | 慢（需转运） | 差 | 否 |

**选择依据**：

1. 赛题**明确给出**现场碎片是镀锌薄铁片（0.3 mm），这是出题人给出的"抓取方式提示"——电磁吸合不必考虑漏气、表面平整度，且吸力可穿透纸片层；
2. 拼接精度判据是**顶点距离 ≤ 2 cm**，直角坐标结构的误差是**开环可预测**的（脉冲当量 × 步数），便于写成设计报告中的"误差分析"；
3. 2 分钟节拍下，点对点直线运动比圆弧插补更省时间，且空程可规划为最短路径；
4. 自备碎片"材质不限、无元器件"，只需保证碎片与吸头之间有铁磁材料或直接选用含铁材质（如铁片贴纸），**同一抓手即可覆盖两项要求**，无需换头。

**机械构成**（自下而上）：

```
底座（铝合金/亚克力，整体刚性、避免共振）
 └─ A4 纸张定位框（L 形定位边 + 压纸片，保证纸张不位移）
 └─ X 轴直线模组（步进电机 + 同步带/丝杠）
     └─ Y 轴直线模组
         └─ Z 轴模组（步进电机，行程覆盖"安全高度 ↔ 断磁位置"）
             └─ 旋转轴（MG996R 舵机，驱动摩擦轮/同步轮实现碎片定向）
                 └─ 电磁铁吸头（下端面加装弹性缓冲垫）
```

### 2.2 视觉识别方案

| 方案 | 实时性 | 鲁棒性 | 开发成本 | 结论 |
| --- | --- | --- | --- | --- |
| **A. 传统机器视觉：LAB 颜色阈值 + 连通域 + 几何解析** | 高（30 fps 级） | 在"纯色碎片、高对比纸面"前提下很好 | 低 | **选定为主力** |
| B. 深度学习目标检测（YOLOv8 / YOLOv11，K230 KPU 推理） | 中（受 NPU 与量化影响） | 依赖训练分布；对"白底扑克牌"这类未见纹理泛化差 | 高（需采集/标注/训练/量化） | 作为**兜底与扩展** |
| C. 特征点 / ArUco 标记定位 | 高 | 需要在碎片上贴标记——赛题**不允许碎片上有元器件与附加物** | —— | 仅用于 A4 纸角点辅助定位 |



### 2.3 拼图求解方案

| 方案 | 适用场景 | 复杂度 | 结论 |
| --- | --- | --- | --- |
| **A. 固定模板匹配（查表）** | 要求 1：自备 4 片，尺寸已知且固定 | O(1) | 基础题**采用** |
| **B. 边匹配 + 回溯搜索 + 几何约束评分** | 要求 2：现场碎片几何未知 | O(边数² × 深度)，n ≤ 4 时极小 | 发挥题**采用** |
| C. 遗传算法 / 模拟退火等全局优化 | 通用 | 迭代不可控，2 分钟节拍下风险大 | 否 |

**公平性说明**：求解器**只读取相机采集的输入图像**，不读取任何文件名、随机种子或真值文件（仿真系统中的 `ground_truth.json` 仅供自动测试使用，求解器不访问），保证算法是"真识别"而非"读答案"。

## 三、系统总体架构

### 3.1 架构框图

```
┌──────────────────────────── K230 CanMV（主控 / 上位机）────────────────────────────┐
│  Sensor 800×480 RGB565                                                            │
│      │                                                                            │
│      ├─► 图像预处理：LAB 阈值分割 → 连通域 → 轮廓/角点                              │
│      ├─► A4 定位：四角点提取 + 平滑 → 原点(0,0) + 分界线                            │
│      ├─► 碎片感知：质心 / 自身角度 / 多边形顶点（mm 坐标）                          │
│      ├─► 稳定锁存：多帧一致性判据 → 锁定初始位姿                                    │
│      ├─► 求解器：模板匹配（基础） / 边匹配回溯（发挥）                              │
│      ├─► 动作规划：每片 8~9 步 → 脉冲数 + 角度 + 磁铁 + 蜂鸣器                       │
│      └─► 本地显示：ST7701 800×480 触摸 UI（三按钮 + EXIT + 状态条）                 │
└───────────────────────────────────┬───────────────────────────────────────────────┘
                                    │ UART1 @115200，34 字节定长帧（0xA5 帧头 + XOR 校验）
┌───────────────────────────────────▼───────────────────────────────────────────────┐
│ 下位机 STM32F407VET6（帧解析 + 多轴闭环步进 + 舵机 PWM + 电磁铁 + 声光）             │
│  帧解析与校验 → 多轴运动执行 → 电磁铁通断 → 蜂鸣器/LED → 限位与急停 → 看门狗        │
└──────┬───────────────┬────────────────┬───────────────┬───────────────────────────┘
       │               │                │               │
   X 轴步进        Z 轴步进        旋转轴舵机        电磁铁 + 声光指示
 (闭环步进)      (闭环步进)       (MG996R)         (蜂鸣器 / LED)
```

### 3.2 数据流（一次完整测评）

```
遮挡移除 → 采集 → A4 定位 → 碎片检测 → 多帧稳定（3.5~7 s）→ 锁存初始位姿
        → 求解（模板 / 回溯）→ 逐片动作序列 → 串口下发 → 下位机执行
        → 全部完成 → 蜂鸣器 + LED 指示 → 显示 DONE
```

## 四、机械结构与纸张布局

### 4.1 A4 纸张与分界线设计

| 项目 | 设计 | 依据 |
| --- | --- | --- |
| A4 颜色 | **深色（近黑）** | 赛题允许颜色自定；碎片为白色/白底图案，深色背景给出最大对比度，直接决定阈值分割的稳定性 |
| 分界线 | 长边中点处，**浅色实线，宽约 3 mm** | 赛题要求实线宽度 ≤ 5 mm 且"明显"；浅色线在深色纸上对比强烈 |
| 半区分割 | 位于长边中点（297 mm ÷ 2 = **148.5 mm**） | 赛题"上半区 / 下半区" |
| 定位方式 | L 形定位边 + 压纸片 | 防止抓取振动导致纸张位移（位移即坐标全错） |

> ⚠️ **坐标约定需现场确认**：现有工程 `main.py` 中 `HALF_LENGTH_PX = (A4_LONG_MM/2)/MM_PER_PX_X`，即把 **297 mm 长边映射到图像 X 轴**，分界线画在 `x = ox + 337 px` 的**竖线**上，同时 `A4_BOTTOM_PX = A4_SHORT_MM/MM_PER_PX_Y = 396 px` 表示 Y 方向覆盖 210 mm。也就是说**现工程把 A4 横放（长边沿机械 X 轴），半区划分沿长边方向**。赛题文字是"上/下区域"，二者只是同一几何关系的摆放朝向差异，但**必须与实际纸张摆位、赛题图示朝向严格对应**，否则会出现"移错了半区"。建议：在正式测评前固定摆位，并把"分界线方向"写成标定项，在报告里用图示明确。

### 4.2 坐标系定义

| 定义 | 取值 | 说明 |
| --- | --- | --- |
| 原点 (0,0) | **A4 左上顶点** | 来自现有方案：机械初始化后先找 A4 顶点，左上顶点作为全域零点 |
| X 方向 | 沿纸张长边向右 | 图像 X 向右 |
| Y 方向 | 沿纸张短边向下 | 图像 Y 向下 |
| 单位 | 统一使用 **mm** | 图像像素必须先换算成 mm 再进入运动规划 |
| 机械零位 | `ZERO_X = 0, ZERO_Y = 0.0` | 每片动作结束后回到零位，保证绝对定位不累积误差 |

### 4.3 Z 轴与抓取头

| 项目 | 设计 | 说明 |
| --- | --- | --- |
| 安全高度 | `Z_SAFE = +18000`（基础题）/ `+16000`（发挥题）脉冲 | 横移时必须抬到此高度，避免刮带已放好的碎片 |
| 下降量 | `Z_DOWN = -18000 / -16000` 脉冲 | 与安全高度对称 |
| 断磁位置 | **Z 轴位置 0** | 现有方案定义：位置 0 即电磁铁断磁（释放）位置 |
| 吸头 | 电磁铁 + 弹性缓冲垫 | 0.3 mm 镀锌铁片易被压弯；缓冲垫吸收 Z 轴过冲 |
| 旋转轴 | MG996R 舵机驱动摩擦轮，`Y_DEG_PER_MM = 360/113 ≈ 3.186 °/mm` | 意味着旋转机构等效周长约 113 mm |
| 释放策略 | Z↓ 放置 → 断磁 → **Z↑ 抬起** → 再横移 | 防止"拖动碎片"破坏已完成的拼接 |

## 六、视觉系统设计

### 6.1 标定

#### 6.1.1 像素 ↔ 毫米换算

现有工程采用**各向异性比例**（相机非正方形视场或存在缩放差异）：

| 参数 | 数值 | 含义 |
| --- | --- | --- |
| `MM_PER_PX_X` | **0.4400 mm/px** | X 方向像素当量 |
| `MM_PER_PX_Y` | **0.5300 mm/px** | Y 方向像素当量 |
| 视场估算 | 800 × 0.44 ≈ **352 mm**；480 × 0.53 ≈ **254 mm** | 覆盖整张 A4（297 × 210 mm）并留余量 |
| `HALF_LENGTH_PX` | (297 ÷ 2) ÷ 0.44 ≈ **337 px** | 分界线在图像中的位置 |
| `A4_BOTTOM_PX` | 210 ÷ 0.53 ≈ **396 px** | A4 在 Y 方向的像素跨度 |

**换算公式**：设 A4 左上角像素为 $(o_x, o_y)$，碎片质心像素为 $(c_x, c_y)$，则

$$
x_{\text{mm}} = (c_x - o_x)\cdot k_x,\qquad y_{\text{mm}} = (c_y - o_y)\cdot k_y
$$

其中 $k_x = 0.4400$，$k_y = 0.5300$。

#### 6.1.2 待补标定项（重要）

| 标定项 | 现状 | 必要性 |
| --- | --- | --- |
| 相机内参与畸变矫正 | 未做 | 视野边缘畸变会直接污染 mm 坐标 |
| A4 四角 / ArUco 定位 | 用深色连通域四角代替 | 已有方案够用，但 ArUco 更稳 |
| 透视矫正（俯视不正） | 未做 | 相机光轴不垂直会产生系统性比例误差 |
| 手眼标定（相机 ↔ 机械原点） | ⚠️ 用经验系数 `DIST_SCALE_X = 0.55`、`DIST_SCALE_Y = 3.8` 代替 | **必须重做**：这两个系数偏离物理量级，说明运动学尚未严格标定 |
| 脉冲当量 | ⚠️ 基础题 `800`、发挥题 `1600` 两套值 | 两套值并存意味着至少一套不准，需统一 |
| Z 断磁位置 / 吸合延时 | 定义清楚（Z=0 断磁） | 需实测"通电到吸稳"的延时 |

**可借鉴的自动标定方案**：工作区 `步进.py` 中已实现一种**动态比例标定法**——不写死像素当量，而是由 A4 的已知物理尺寸反算：

$$
k_x = \frac{297}{w_{\text{px}}},\qquad k_y = \frac{210}{h_{\text{px}}}
$$

其中 $w_{\text{px}}, h_{\text{px}}$ 取 A4 矩形**对边长度均值**以抵消单边误差；比例系数再用 EMA（α = 0.1）平滑，**连续 20 帧后冻结基准**。这一做法把"相机高度/焦距变化"自动吸收进当量，比固定 `MM_PER_PX_X = 0.44` 更稳健，**建议在正式方案中采用并写入报告**。

另外 `get_rect_ui.py` 中对矩形跟踪使用了**卡尔曼滤波**（Ts = 0.5，Q = 1e-4，R = 1e-3，P = 10I，融合系数 α = 0.3），可作为 A4 四角跟踪的备选方案，进一步抑制振动噪声。

### 6.2 A4 纸张定位

```
find_blobs(LAB = BLACK_A4_TH, pixels_threshold=15000, area_threshold=15000, merge=True, margin=10)
        ↓ 取面积最大的连通域
双重角点估计
  ├─ 反算角点：由 blob 的 (cx, cy, w, h, rotation_deg) 重建外接矩形四角
  └─ 原始角点：blob.corners()
        ↓ 自适应融合
  偏差 d > 25 px  →  原始角点权重 0.15、反算角点权重 0.85（抑制离群点）
  偏差 d ≤ 25 px  →  原始角点权重 0.60、反算角点权重 0.40
        ↓ 时序平滑（EMA，α = 0.2）
  稳定四角 → 按 (x+y) / (x−y) 极值分类为 左上 / 右上 / 右下 / 左下
        ↓

```

### 6.3 碎片感知

1. **分割**：在 A4 ROI 内按白色阈值提取连通域，按像素数降序取前 4 个（赛题上限 4 片）；
2. **质心**：`(cx, cy)` → mm 坐标，作为碎片位置描述量；
3. **自身角度**：取轮廓中**距离质心最远的角点**，则

$$
\theta = \operatorname{atan2}\!\left(\Delta x,\; -\Delta y\right),\quad \theta \in [0^\circ, 360^\circ)
$$

即以"质心 → 最远角点"这条射线作为碎片的**特征方向**，图像 Y 轴向下时用 $-\Delta y$ 保证角度定义符合右手习惯。该定义在碎片旋转时保持连续，是计算旋转量的基础。

4. **多边形重建**（发挥题）：取 `blob.corners()` 的顶点，换算为 mm 并按相对质心的**极角排序**，得到顶点序一致的凸多边形 `polygon_mm`，供边匹配求解器使用。

### 6.4 多帧稳定锁存

赛题说明要求"移除遮挡后一键启动"，因此启动瞬间画面会剧烈变化。稳定判据为：

$$
\text{stable} \iff \forall i:\; \sqrt{(c_{x,i}^{(t)}-c_{x,i}^{(t-1)})^2+(c_{y,i}^{(t)}-c_{y,i}^{(t-1)})^2} \le 10\ \text{mm}
\;\wedge\; \Delta\theta_i \le 12^\circ
$$

| 场景 | 稳定阈值 | 连续稳定时长 |
| --- | --- | --- |
| 基础题（自备 4 片） | 位移 ≤ 10 mm，角度 ≤ 12° | **3.5 s** |
| 发挥题（现场碎片） | 同上 | **7.0 s** |

界面以**进度条**显示稳定进度（`x.x s / N s`），便于现场判断。锁存后不再更新初始位姿，避免机械振动引起的重检测导致"目标漂移"。

### 6.5 阈值在线标定

`change_threshold.py` 提供图形化调阈值界面，配合主页按钮进入；调整结果**写入 SD 卡 `lab_config.json`**，掉电保存。这是"适应正常室内照明、不得要求特殊照明"这一条的唯一可靠解法——**每次换场地只需 30 秒重标定**。

## 七、拼图算法设计

### 7.1 要求 1（自备 4 片）：模板匹配 + 间隙扩展

**思路**：自备碎片尺寸与颜色完全已知，且赛前可以任意摆放标定，因此采用**查表法**——预存 4 片碎片在下半区的目标位姿：

| 碎片 | 目标 X (mm) | 目标 Y (mm) | 目标角度 (°) |
| --- | --- | --- | --- |
| P1 | 200.0 | 86.0 | 204.0 |
| P2 | 235.0 | 112.0 | 12.0 |
| P3 | 210.0 | 118.0 | 17.0 |
| P4 | 193.0 | 136.0 | 20.0 |

**间隙扩展（GAP_SPREAD_MM = 5.0）**：把 4 个目标点各自沿"目标中心 → 目标点"方向**外推 5 mm**。

$$
\text{target}'_i = \text{target}_i + 5.0 \cdot \frac{\text{target}_i - \bar{c}}{\|\text{target}_i - \bar{c}\|}
$$

目的：先按"留缝"的方式粗放，杜绝抓放过程中的**相邻碎片干涉与带倒**；缝隙由后续精修（或直接落在 2 cm 判据内）消化。这一策略把"一次成功的概率"最大化，符合"2 分钟内一次性完成"的赛制。

### 7.2 要求 2（现场 ≤ 4 片）：边匹配 + 回溯搜索

#### 7.2.1 算法流程

```
输入：n 个碎片多边形（mm 坐标，≤4 片，每片 ≤5 条边）
 ① 提取全部边：记录 (碎片号, 边号, 边长, 起点, 终点)，边总数 ≤ 20
 ② 边长匹配：对任意两条不同碎片的边，若满足
        |l_a − l_b| ≤ max( ε_abs , ε_rel · min(l_a, l_b) )
    其中 ε_abs = 2.5 mm，ε_rel = 5.5%，则互为候选匹配边
 ③ 回溯搜索：以第 0 片固定为基准（位姿 = 单位变换）
      递归地将未放置碎片 j 的候选边，与已放置碎片 i 的候选边"边对边"重合：
        · 计算刚体变换（旋转 θ + 平移 t）使 src 边 → tgt 边
        · 剪枝 1：与已放置碎片的重叠面积 > 80 mm² → 丢弃
        · 剪枝 2：整体包围盒超过目标矩形上限 + 10 mm → 丢弃
        · 剪枝 3：搜索状态数 > 30000 → 中止（防止 2 分钟超时）
 ④ 评分选优：对每个完整布局计算代价函数，保留 score < 60 的解
 ⑤ 输出：最优布局的每片 (c, s, tx, ty) 刚体变换 + 整体矩形宽高
```

#### 7.2.2 刚体变换的构造

设待放置碎片的一条边为 $\overline{P_aP_b}$，参考碎片上要与之重合的边为 $\overline{Q_aQ_b}$，则旋转角与平移为：

$$
\theta = \operatorname{atan2}(Q_a - Q_b) - \operatorname{atan2}(P_a - P_b)
$$

$$
R(\theta) = \begin{bmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{bmatrix},\qquad
t = Q_b - R(\theta)\,P_a
$$

于是碎片上任意顶点 $p$ 变换后为 $p' = R(\theta)\,p + t$（实现见 `rigid_edge_align` 与 `transform_polygon`）。

#### 7.2.3 代价函数（评分）

$$
J = 100\cdot e_{\text{fill}} + 300\cdot r_{\text{overlap}} + 20\cdot\left(w_{\text{out}} + h_{\text{out}}\right)
$$

| 项 | 定义 | 权重 | 物理含义 |
| --- | --- | --- | --- |
| $e_{\text{fill}}$ | $\dfrac{w h - \sum A_i}{w h}$ | 100 | 布局填充误差率，衡量"拼出来是不是严丝合缝的矩形" |
| $r_{\text{overlap}}$ | $\dfrac{\text{重叠面积}}{\sum A_i}$ | 300 | **最高权重**——赛题明确"碎片不重叠"，一旦重叠该项直接判负 |
| $w_{\text{out}}$ | $\max(0,\; W_{\min}-w,\; w-W_{\max})/30$ | 20 | 宽度越出 90~120 mm 的惩罚 |
| $h_{\text{out}}$ | $\max(0,\; H_{\min}-h,\; h-H_{\max})/40$ | 20 | 高度越出 50~90 mm 的惩罚 |

搜索区间取 $W \in [82, 128]$ mm、$H \in [42, 98]$ mm（较赛题区间留裕量，兼顾多边形提取的量化误差）；只有 $J < 60$ 的布局被接受，否则判为求解失败并自动重试。

#### 7.2.4 重叠面积的计算

采用**包围盒预筛 + 网格点采样**：先做包围盒互斥检查（快），通过后在交叠区域内以 2 mm 网格做点在多边形内测试，统计双inside的网格数乘网格面积。精度足够（赛题判据是 cm 级），且比精确多边形裁剪（如 Sutherland–Hodgman）**代码量小、无浮点异常风险**，适合嵌入式实时运行。

#### 7.2.5 目标位置（下半区）

$$
x_{\text{rect}} = \frac{297}{2} - \frac{w}{2} \quad(\text{沿长边居中}),\qquad
y_{\text{rect}} = 0.75 \times 210 - \frac{h}{2}
$$

即**矩形沿长边居中，位于另一方向的 75% 位置**（对应"下半区"）。每片碎片的目标质心由最优布局中的多边形顶点均值 + 上述偏移得到。

#### 7.2.6 扑克牌花纹的接缝一致性（30 分关键项）

在几何解集 $\{J < 60\}$ 内，进一步用**接缝两侧的颜色连续性**挑选最优候选：对每一对相邻碎片的公共边，取两侧各若干像素宽的条带，比较条带内的颜色/灰度分布（直方图距离或梯度连续性），接缝越连贯得分越高。工作区的仿真系统（`puzzle_core/solver.py`）已实现"先找几何可行解，再用接缝两侧颜色连续性选择候选"这一策略，可直接移植到 K230 上（用 DMA 读取 ROI 行缓冲取条带，避免整帧遍历）。

⚠️ **现状与差距（必须正视）**：仿真系统 README 中描述的 **SIFT + RANSAC 特征匹配、碎片圆角恢复、纹理消歧**三项增强，在 `main.py` 中**尚未实现**——发挥题目前仍用 `blob.corners()` 的**四角近似**多边形。这意味着：

- 现场碎片是**带圆角的扑克牌牌面**（圆角半径约 4 mm），四角近似会在角部引入可观的几何误差，直接吃掉"顶点距离 ≤ 2 cm"的裕量；
- 花纹对应正确（30 分）**完全依赖**接缝纹理评分，而该功能目前只存在于仿真系统中。

**这是冲击要求 2 第（2）项 30 分的最大缺口**，建议列为竞赛期间的最高优先级开发项：① 用 `find_rects` / 轮廓逼近（`approx`）得到真实多边形而非四角；② 移植接缝纹理评分；③ 若时间允许再考虑 SIFT+RANSAC。

| `MOTOR_RPM_X / Z` | 280 / 400 | —— | 转速 |
| `SERVO_DEG_SEC` | 320 °/s | —— | 舵机角速度 |

> ⚠️ **必须在报告中明确处理**：`DIST_SCALE_X = 0.55`、`DIST_SCALE_Y = 3.8` 属于调试期间的经验系数，会掩盖真实的机械比例关系。正式方案应通过**实测标定**（指令走 100 mm，测量实际位移，取比值）替换为物理脉冲当量，并把标定过程写成设计报告的"测试方案"内容。

**下位机侧的电机指令（Emm 固件）**：ZDT_X42S 采用通信地址寻址，`0x01` 为 Z 轴（USART3，PC10/PC11）、`0x02` 为 X 轴（UART2，PA2/PA3），帧尾固定 `0x6B`，驱动电流约 1200 mA；运动使用**位置模式（功能码 `0xFD`）与相对模式**，实测参数为 `vel = 150`、`acc = 5`。使能与清零点等控制指令形如 `[addr, 0xF3, 0xAB, 1, 0, 0x6B]`（使能）、`[addr, 0x0A, 0x6D, 0x6B]`（清零点）。**这些是设计报告"程序设计"部分可以直接引用的具体依据**。

**节拍提示**：`vel = 150` 与 `MOTOR_RPM_X = 280`、`MOTOR_RPM_Z = 400` 之间存在不一致（上位机按时延估算等待，下位机按自身速度执行）。二者必须统一，否则会出现"上位机以为到位了、下位机还在走"的动作截断。建议：① 统一速度参数；② 或按 [E-1](#e-1-代码缺陷开工即修否则现场无法正常运行) 的 D4 方案加 ACK 回传，用真实到位信号驱动节拍。

### 8.2 运动延时估算（开环等时）

下位机执行期间，上位机按"最长轴耗时 + 固定余量"等待：

$$
T = \max\!\left(\frac{|\Delta X|}{v_x},\ \frac{|\Delta Z|}{v_z},\ \frac{|\Delta Y_{\deg}|}{320},\ \frac{|\Delta\theta_{\deg}|}{320}\right) + T_{\text{margin}}
$$

其中 $v_x = \text{MOTOR\_RPM\_X} \times \text{PPR}/60$，$v_z$ 同理，$T_{\text{margin}} = 1500$ ms。

| 动作类型 | 等待时间 |
| --- | --- |
| 纯开关量（吸合 / 释放 / 蜂鸣器） | `MAG_MS = 500` ms |
| 含运动的动作 | 上式结果 |
| 每片完成后的整定 | `PIECE_MS = 1000` ms |

**要点**：取多轴耗时的**最大值**而不是求和，是多轴并行带来的直接节拍收益（Z 轴升降与 XY 横移同时进行）。代价是需要下位机做真正的插补；若下位机为顺序执行，则必须改为求和，否则会"没到位就发下一条"。

### 8.3 串口通信协议（34 字节定长帧）

**帧结构**：

| 偏移 | 长度 | 字段 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| 0 | 1 B | 帧头 | —— | 固定 `0xA5` |
| 1 | 4 B | ΔX 脉冲 | int32 | 正值/负值决定方向 |
| 5 | 4 B | ΔZ 脉冲 | int32 | 同上 |
| 9 | 2 B | ΔY 角度 | int16 | **实际值 × 10**（0.1° 分辨率） |
| 11 | 2 B | Δθ 角度 | int16 | **实际值 × 10** |
| 13 | 1 B | 磁铁 | uint8 | `0x01` 吸合，`0x00` 释放 |
| 14 | 1 B | 蜂鸣器 | uint8 | `0x01` 响 |
| 15 | 18 B | 保留填充 | —— | 全 0，便于后续扩展（限位查询、回零、急停） |
| 33 | 1 B | 校验 | uint8 | 前 32 字节**逐字节异或** |

**帧长核算**：1（帧头）+ 12（`<2i2h` 结构体）+ 20（磁铁 1 + 蜂鸣器 1 + 填充 18）+ 1（校验）= **34 字节**。

**发送实现**：

```python
useful  = struct.pack("<2i2h", int(x_p), int(z_p), int(y_deg*10), int(t_deg*10))
padding = bytes([0x01 if magnet_on else 0x00]) + bytes([0x01 if buzzer else 0x00]) + bytes([0]*18)
payload = useful + padding
cksum = 0
for b in payload: cksum ^= b
uart.write(b"\xA5" + payload + bytes([cksum & 0xFF]))
```

**协议设计评价**：定长 + 位域清晰 + 弱校验，下位机解析零歧义；缺点是**无应答机制**——建议在保留字节中扩展 `ACK / 状态回传（限位、故障码）`，形成闭环节拍，把"开环等时"升级为"到位即走"，可再压缩 20~30% 时间。

### 8.4 动作序列设计

#### 基础题：8 步直连（不回零）

| 步 | 动作 | 磁铁 | 设计意图 |
| --- | --- | --- | --- |
| 1 | Z↑ 安全高度 | 松开 | 仅在首片执行一次 |
| 2 | → 碎片上方 | 松开 | 直连（从当前位置出发，不先回零） |
| 3a | Z↓ 到断磁位置 | 松开 | |
| 3b | 吸合 | **吸住** | 保持 500 ms 确保吸稳 |
| 4 | Z↑ 抬起 | 吸住 | |
| 5 | → 目标位姿（含旋转 θ） | 吸住 | 平移与旋转同时进行 |
| 6a | Z↓ 放置 | 吸住 | |
| 6b | 释放 | 松开 | |
| 7 | 空载抬起 | 松开 | **先抬再走**，避免刮带 |
| 8 | 回零 | 松开 | 4 片共 ≈ 36 包 |

**空程最短化**：基础题允许"src → dst 直连"，只在每片结束回零。相比每步都回零，可节省约 4 段全行程。

#### 发挥题：9 步回零（绝对定位）

| 步 | 动作 | 磁铁 |
| --- | --- | --- |
| 1 | Z↑ 安全高度 | 松开 |
| 2 | → 抓取点 | 松开 |
| 3a / 3b | Z↓ / 吸合 | 吸住 |
| 4 | 抬起 | 吸住 |
| 5 | **带料回零**（−Δsrc） | 吸住 |
| 6 | → 目标位姿（+Δdst） | 吸住 |
| 7a / 7b | Z↓ 放置 / 释放 | 松开 |
| 8 | 空载抬起 | 松开 |
| 9 | 空载回零 | 松开 |

**为什么发挥题要"带料回零"**：现场碎片几何未知，目标位姿由求解器逐片计算，采用**绝对定位**（每次都从机械零位出发）可以把机械反向间隙、皮带弹性回差的影响限制在单段行程内，避免逐片累积——这是保证 ≤ 2 cm 顶点判据的结构性措施。

### 9.2 任务状态机

```
        ┌──────────┐   A4 未找到 → 提示 "Searching Black A4..."
        │  DETECT  │   碎片数不足 → 提示 "Pieces: k/4"
        └────┬─────┘
             │ 检测到合规碎片
        ┌────▼─────────┐   帧间位姿超差 → 回到 DETECT
        │ STABILIZING  │   连续稳定 3.5 s（基础）/ 7.0 s（发挥）
        └────┬─────────┘
             │ 锁存初始位姿
        ┌────▼────┐   模板查表（基础） / 回溯求解（发挥）
        │ SOLVING │   求解失败 → 打印 [SOLVER] 求解失败! → 回到 DETECT 重试
        └────┬────┘
             │ 得到每片目标位姿
        ┌────▼────┐   逐包下发 + 动态延时
        │  SEND   │
        └────┬────┘
             │ 全部完成
        ┌────▼────┐   蜂鸣器 + LED → 显示 "DONE"（保持并刷新位姿信息）
        │  DONE   │
        └─────────┘
```

**健壮性设计**：

- `os.exitpoint()` 每次循环调用，保证 IDE/串口可随时中断；
- `gc.collect()` 周期回收，避免 MicroPython 堆碎片导致长时间运行崩溃；
- 触摸读取使用 `tp.read(5)` 一次取出**全部待处理触摸点**，防止快速点击漏检；
- `while tp.read(1): sleep(20)` 在进入任务前等待**触摸释放**，避免"按下的那一下被任务内按钮误判"；
- 求解失败、碎片数变化都会**自动回到检测态**，符合"中途无人工干预"。

## 十一、两分钟节拍预算

| 阶段 | 设计耗时 | 依据与优化手段 |
| --- | --- | --- |
| 遮挡移除 → 稳定锁存 | 3.5 s（基础）/ 7.0 s（发挥） | 多帧一致性判据；可缩短但不建议低于 3 s，避免误锁存 |
| A4 定位 + 碎片检测 + 求解 | 1 ~ 3 s | 求解是秒级；基础题为查表，可忽略 |
| 单次取放循环 | 8 ~ 12 s | Z 升降 ±18000 脉冲、XY 全行程、旋转定位、磁铁 500 ms、整定 1000 ms |
| 4 片总动作时间 | 32 ~ 48 s | 8~9 步/片，取多轴并行最大值而非求和 |
| 结束指示 | < 1 s | 蜂鸣器 + LED |
| **合计** | **约 40 ~ 60 s** | **预留 ≥ 60 s 用于异常重试** |

**节拍优化的四个着力点**：

1. **求解前置**：在抓取第一片之前完成全部求解，运动期间不再做重计算；
2. **多轴并行**：Z 升降与 XY 横移重叠执行；
3. **空程最短化**：基础题 src → dst 直连不回零；
4. **降级保底策略**：若时间过半仍有碎片未进入下半区，切换为"只搬运不精拼"模式，先确保拿到 50 分中的 20 分，再争取拼接 30 分。

## 十二、风险分析与对策

| 风险 | 影响 | 概率 | 对策 |
| --- | --- | --- | --- |
| 现场光照变化导致阈值失效 | 分割失败，无法启动 | 高 | 图形化阈值一键标定 + SD 卡持久化；加装简易遮光罩（不构成"特殊照明"） |
| 白色碎片 + 浅色纸对比不足（现场纯白） | 碎片漏检/粘连 | 高 | 自备 A4 选**深色**；必要时改用阴影/边缘法二次分割 |
| 扑克牌花纹相似度高 | 拼错接缝（花纹不对应） | 中 | 接缝两侧颜色连续性评分；增加纹理直方图比对 |
| 0.3 mm 铁片被压弯或吸住不回位 | 碎片变形、释放失败 | 中 | 弹性缓冲吸头 + 断磁位置归零 + 释放后先抬 Z 再横移 |
| 抓取时碎片未被吸住 | 空抓，浪费时间 | 中 | 抬起后做一次视觉复核（碎片是否随吸头移动）；失败则重试一次 |
| 相邻碎片干涉/带倒 | 已放置碎片被撞偏 | 中 | `GAP_SPREAD_MM = 5.0` 间隙扩展；先粗放后精修 |
| 求解失败或超时 | 无法完成拼接 | 中 | 搜索状态数上限 30000；失败回到检测态重试；必要时放宽尺寸约束 |
| 机械反向间隙与累积误差 | 顶点误差超 20 mm | 中 | 发挥题采用**每片回零的绝对定位**；⚠️ 用正式脉冲当量替换 `DIST_SCALE_*` 经验系数 |
| 串口丢包/误码 | 动作缺失或错乱 | 低 | 34 字节定长帧 + XOR 校验；建议扩展 ACK 与重发；下位机看门狗 |
| 2 分钟超时 | 全部失分 | 低 | 节拍预算留有 60 s 余量；降级保底策略 |
| 纸张被拖动位移 | 全局坐标错乱 | 低 | L 形定位边 + 压纸片；每片前后复核 A4 四角是否漂移 |
| MicroPython 长时间运行内存碎片 | 程序崩溃 | 低 | 周期 `gc.collect()`；避免循环内频繁创建大对象 |
| **求解器只有状态数上限、无墙钟超时保护** | 极端布局下求解耗时不可控，直接吃掉 2 分钟预算 | 中 | 增加墙钟计时（如 20 s 硬超时），超时后回退到"只搬运不精拼"的保底策略 |
| **「调阈值」按钮存在参数不匹配** | 一键调用即抛 `TypeError`，现场无法标定阈值 | 高 | `main.py` 以 7 个实参调用 `run_threshold_ui`，而 `change_threshold.py` 只接收 5 个形参，需统一签名 |
| **`libs.otherKey` 模块缺失** | `from libs.otherKey import YbKey1/2/3` 导入失败，程序无法启动 | 高 | `ybUtils` 目前位于 `25电赛k230图像化\` 下，需整体拷贝到 SD 卡根目录并补齐 `libs/otherKey.py` |
| **发挥题仍是四角近似多边形** | 圆角扑克牌碎片的角部几何误差偏大，纹理对应功能缺失 | 高 | 见 [7.2.6](#726-扑克牌花纹的接缝一致性30-分关键项) |
| 无物理限位开关，回零靠软件零点 | 丢步或撞限位无保护，可能损坏机构 | 中 | 补装 X/Z 限位开关与硬件急停；回零指令（Emm 0x93/0x4C/0x9A/0x9C）目前仅在 `K230_串口通讯控制.py` 中定义、尚未调用 |
| 三套串口协议并存易混用 | 调试时误接协议导致动作错乱 | 中 | 明确以 **34 字节帧**为主协议；演示用 `k230_protocol.py`（`A5 5A + Len + Cmd + Data + CRC8`）、`CV_lite混合.py`（`AA FF + func + len + x + y + sc + ac`）与上届云台 `control.py`（0xF1/0xFC）**一律不接入本装置** |
